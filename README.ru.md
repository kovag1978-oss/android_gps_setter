GPS Setter — Xposed-модуль для подмены геолокации на Android. Можно задать координаты для всей системы или назначить отдельные координаты выбранным приложениям. Все активные подменённые местоположения отображаются на карте. Избранные места можно выбирать голосом через плитку быстрых настроек Android; пока подмена работает, foreground service поддерживает видимый статус.

> **Требования:** Android 8.1 или новее и совместимая среда Xposed, например LSPosed или Vector. Для LSPosed/Vector обычно требуется root. LSPatch также можно использовать, встроив модуль в целевое приложение.

## Настройка

1. Установите APK и включите **GPS Setter** в LSPosed или Vector.
2. В области действия менеджера включите **Android System** (`android`) для системной подмены. Для подмены только в приложениях это необязательно.
3. Для варианта Full включите **Сервисы Google Play** (`com.google.android.gms`), если целевое приложение использует API геолокации GMS. Для FOSS при необходимости включите соответствующий пакет microG.
4. Для подмены в выбранном приложении добавьте его в область действия менеджера. Выбор приложения в GPS Setter сам по себе не меняет область действия LSPosed/Vector — её нужно настраивать в менеджере.
5. Выберите место и примените его в GPS Setter. После изменения области действия перезапустите целевые приложения; системным хукам может потребоваться перезагрузка устройства.

## Раздельное местоположение приложений

1. Откройте **Настройки → Включить раздельное управление**, затем выберите **Приложения для раздельного управления**.
2. Назначьте каждому приложению уникальную голосовую команду и цвет маркера, затем включите его профиль. В список доступных приложений также входят установленные Сервисы Google Play и Сервисы Google.
3. Выберите место на карте или в избранном. Нажмите кнопку применения и выберите приложение или пункт **Все**, чтобы обновить все включённые профили.
4. Когда профили активны, нажмите отдельную кнопку остановки и выберите профиль или пункт **Все**. Системное местоположение показывается в списке, если системная подмена активна. Долгое нажатие не используется.

Для каждого активного профиля приложения показывается своё ongoing-уведомление. Новое место обновляет уведомление только выбранного приложения; остановка профиля убирает только его уведомление. Пункт **Все** останавливает все профили приложений и системную подмену.

## Голосовое управление

Добавьте плитку GPS Setter в быстрые настройки Android и нажмите её, чтобы открыть системное распознавание речи. Открывать сам экран GPS Setter не требуется.

- При включённом раздельном управлении первый запрос перечисляет команды включённых приложений и избранные места, а также помечен как **«Шаг 1 из 2»**.
- Назовите избранное, чтобы за один шаг применить место ко всем включённым профилям, или скажите **«выключить»**, чтобы остановить системную подмену и подмену во всех приложениях.
- Назовите команду приложения, чтобы выбрать его. После короткой паузы начнётся **«Шаг 2 из 2»** с названием выбранного приложения: назовите избранное, чтобы задать ему место, или скажите **«выключить»**, чтобы остановить подмену для этого приложения.
- При выключенном раздельном управлении назовите избранное для системной подмены или скажите **«выключить»**, чтобы её остановить.
- Команды приложений должны быть уникальными и не могут совпадать с командой остановки (**«выключить»** в русском интерфейсе, **“turn off”** в английском). Название места распознаётся и внутри более длинной фразы. Если совпадения не найдено или ввод отменён, текущее состояние подмены не меняется.

Подсказка распознавания включает заданные команды приложений и названия сохранённых мест. Если список длинный, приложение распознавания речи может обрезать подсказку.

## Карта и активные уведомления

- На карте показываются все активные подменённые местоположения: системное и назначенные приложениям. Маркеры перемещаются при смене координат и исчезают после остановки подмены.
- Цвет маркера каждого приложения настраивается рядом с его голосовой командой. У системного маркера свой цвет, а маркер, установленный нажатием на карту, чёрный.
- Близкие активные маркеры объединяются в кластеры с хорошо видимыми цветными точками. Нажмите на кластер, чтобы раздвинуть его маркеры вокруг центра и соединить их линиями с исходными местами. При перемещении карты паук закрывается, а кластеры пересчитываются.
- Активные уведомления нельзя убрать обычным смахиванием; пока работает любая системная или приложенческая подмена, также запущен foreground service. Android или оболочка устройства всё ещё могут остановить приложение либо отключить его уведомления.

## Возможности

- Системная подмена геолокации или подмена отдельно для выбранных приложений через Xposed.
- Независимые координаты, голосовые команды и цвета маркеров для приложений.
- Отображение всех активных подменённых мест на карте, цветные кластеры и раскрытие «паучком».
- Случайное смещение координат рядом с выбранным местом.
- Избранные места с импортом и экспортом.
- Постоянные уведомления и foreground service во время подмены.
- Варианты Full и FOSS с разными картами и провайдерами геолокации.

## Как это работает

Модуль перехватывает API геолокации Android, включая `Location` и `LocationManager`, и передаёт целевым приложениям заданные координаты. Системные хуки поддерживают изменения службы геолокации, появившиеся в Android 14 и новее. Xposed-менеджер определяет, в каких процессах работает модуль; GPS Setter не может самостоятельно менять эту область действия.
